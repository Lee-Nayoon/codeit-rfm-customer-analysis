## 🎯 1. 분석 개요
* **목적:** 대형 마켓 고객 데이터를 활용하여 고객별 **최근성(Recency), 구매 빈도(Frequency), 구매 금액(Monetary)**을 정량화하고, 이를 바탕으로 고객 등급(RFM 세그먼트)을 분류하여 **등급별 매출 기여도 파악 및 타겟 마케팅 전략을 제안**합니다.
* **사용 도구:** `Python` (`Pandas`, `Matplotlib`, `Seaborn`)
* **최종 산출물:** 고객 등급별 매출 기여도 시각화 차트 및 타겟 마케팅 제안서

## 📂 2. 데이터셋 개요
* **총 관측치 수 (Rows):** 2,240개
* **수집 변수 수 (Columns):** 23개

* **데이터 정제:** 결측치 및 중복값 제거, 이상치(age, annual_income) 제거를 통해 분석 신뢰도 확보

## 🛠️ 3. 데이터 전처리 및 분석 과정

### 🔍 파생변수 생성 및 데이터 가공
1. **고객별 총 구매 금액 (`amount_total`)**: 술, 과일 등 6개 개별 상품 카테고리 데이터를 행 방향(`sum(axis=1)`)으로 합산하여 정의
2. **고객별 총 구매 횟수 (`num_purchase_total`)**: 웹, 가맹점 등 3개 구매 환경 카테고리 데이터를 행 방향(`sum(axis=1)`)으로 합산하여 정의
3. **연령대 구간화 (Binning)**: 나이 데이터를 10세 단위로 구간화한 후, 데이터 수가 적은 구간을 유의미하게 병합 (`10대·20대` ➔ `20대 이하`, `60대·70대` ➔ `60대 이상`)

### 🚨 트러블 슈팅 (Troubleshooting)
* **문제 상황:** `pd.cut()`으로 가공된 범주형(Categorical) 데이터의 값을 변경하려 할 때 `TypeError` 발생
* **해결 방법:** 문자열(`astype(str)`)로 명시적 형변환을 거친 후 `.replace()`를 적용하는 전처리 프로세스 구축
* **인사이트:** 데이터 타입 제약 조건을 이해하고 이를 우회하여 전처리 안정성을 확보하는 데이터 핸들링 역량 증명

## 📐 4. RFM 고객 등급 설계 기준
분석의 왜곡을 방지하고 군집의 신뢰도를 높이기 위해, 빈도와 금액 산정 시 **상대평가 기법(`pd.qcut`)**을 도입하여 등급을 부여했습니다.

* **Recency (최근성):** 마지막 구매일이 최근일수록 높은 등급 (3점 ➔ 2점 ➔ 1점)
* **Frequency (빈도):** 구매 횟수가 많을수록 높은 등급 (1점 ➔ 2점 ➔ 3점)
* **Monetary (금액):** 총 구매 금액이 많을수록 높은 등급 (1점 ➔ 2점 ➔ 3점)

---

## 📈 5. 최종 분석 결과 및 시각화
* **시각화 최적화:** RFM 세그먼트별 매출액을 그룹화한 **파이 차트(Pie Chart)**를 생성할 때, 데이터 정렬 순서와 차트 라벨 순서를 완벽히 일치시켜 **시각적 데이터 왜곡을 차단하고 가독성을 극대화**했습니다.
* **지표별 특징:** `Recency` 등급은 등급 간 매출 기여도 차이가 크지 않은 반면, `Frequency`와 `Monetary` 등급은 등급 간 매출 기여도 격차가 매우 크게 발생함을 확인했습니다.
* **핵심 발견:** RFM 등급별 매출 기여도에서 최상위인 3등급보다 **2등급의 매출 기여도가 더 높음**을 발견했습니다.
